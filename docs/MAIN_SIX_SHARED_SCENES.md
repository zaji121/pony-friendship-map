# 48-question form v2: main-six distinctions

2026-10-30. This is an experimental content revision, not a validated character classifier. The original entrance, complete reports and 36-role roster remain intact.

## What changed

Four existing task slots (indices 1, 2, 9, 13) compare concrete responses to a shared problem instead of offering unrelated hobby destinations. Total remains 32 framework items + 14 fixed activity items + 2 final slots = 48 single-choice questions.

The existing final slots have 15 pair-specific scenarios covering all unordered pairs of the main six. They are used only when those two roles rank first and second and remain close. Other pairings retain the generic trait-based contrast. If no contrast applies, an ordinary task occupies that slot. There are no additional questions, fixed main-six bonuses or per-role quotas.

|Editorial distinction|Shared situation used in questions|Evidence boundary|
|---|---|---|
|Twilight: organizing and explaining|Check dependencies and handoffs; clarify why a step fails|Studying is not an I/N/T key. The scene is an analogy, not a quoted episode.|
|Applejack: practical follow-through|Take and complete a concrete job; repair equipment for next use|Work ethic is not an MBTI endpoint and is not exclusive to Applejack.|
|Rainbow Dash: practice and performance|Try the route, repeat the movement and adjust it|Athletics does not establish E/S/T; reckless behavior is not rewarded.|
|Pinkie Pie: participation through playful changes|Change the game so people can join without performing|Not all sociability or happiness maps to Pinkie.|
|Fluttershy: individual comfort and support|Listen first, offer a manageable task and practical support|Shyness is not I, and caring is not an exclusive F indicator.|
|Rarity: fitting a crafted result to the person|Try the garment in motion, adjust fit, colors and accessories|Aesthetics is an activity association, not an MBTI measurement.|

These distinctions reuse shared feature tags associated with multiple roles. An option never directly names or assigns a character. Repeated patterns, framework responses and the final contrast jointly influence ranking. Non-selected options do not establish that a character or user dislikes an activity.

## Checks and limitations

All 36 active roles retain a strict first-place synthetic answer witness. The 15 main-six contrasts pass both candidate orientations; selected actions remain traceable in report explanations. MBTI axis answers and scores are unaffected by task choices. The server retains v1 of the 48-total form, both earlier narrative editions and the original core-only scorer.

On the same 20,000-trial independent-uniform simulation design, main-six share changes from 24.075% to 26.99%. Close results change from 42.07% to 42.425%; Sweetie Belle's share increases from 7.42% to 8.455%. These latter findings do not show improved discrimination. There is no evidence here of higher human classification accuracy. The variant is published only to the narrative trial entry, not substituted for the default core-only experience or historical results.

The content change makes the questions more specific, but empirical discrimination, reliability, retest stability and role agreement still require participant studies. Uniform random proportions are not target population rates; equalizing them would not establish validity.
