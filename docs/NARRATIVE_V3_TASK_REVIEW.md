## 改了什么

- 四幕各补1道任务题，共48道四维题＋16道任务题，接近时仍最多追问3次。
- 增加食品制作、果园与搬运两类活动，补入运动和经营的角色线索。它们只用于剧情联想，不计入MBTI四维。
- 食品制作关联同时用于苹果嘉儿、碧琪、舒歌贝、梨子酱、史密夫婆婆、麦托什；果园劳动同时用于苹果嘉儿、麦托什、辉麦、史密夫婆婆、苹果丽丽。不是苹果嘉儿或主角团专属加分。
- 四维／兴趣权重维持60%／40%，没有按角色名称加分、配额或随机替换。
- 动态追问优先对比候选之间较有辨识度的活动差异，仍允许“都愿意”和“说不准”。

## 检查方法与结果

同批20,000次合成输入保留原48题答案和原12道任务选择，只为新增4题生成独立随机选择。v2与v3分别执行自身的动态追问，均不排除接近结果。

- 苹果嘉儿第一候选约1.53% → 3.87%。
- 主角团合计约18.52% → 25.10%。
- 接近候选约28.38% → 32.86%。这个指标变差，不能只拿主角团比例上升宣称准确性提高。
- 36位均有严格第一的合成作答；这只证明可达性。
