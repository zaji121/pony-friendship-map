# Form v4: chapter openings, wording and four adaptive slots

2026-10-30. Keeps the original Derpy entrance and full reports. Total remains 48: 32 four-preference items, 12 fixed task scenes, and 4 final scene slots. A final slot selects a candidate contrast when applicable, otherwise the corresponding ordinary scene. This is still an experimental fictional-content association, not a validated personality instrument.

## User-facing revisions

- Entrance heading: 来自小马谷的一封信. Its font-readiness preflight uses the same new wording.
- Four chapter openings restored to the narrative flow, using the existing Twilight, Rarity, Pinkie and Applejack assets and existing frame treatment. Assets are decoded before showing the native dialog. The background's layout and scroll position are preserved; dismissing marks that chapter as seen in the current draft.
- The 单选题 label is removed from markup and controller. Selecting an option still selects exactly one answer.
- Displayed question 26 selects one finished photo caption, comparing concrete details with overall theme. The old first-answer/then-another wording is removed.
- Displayed question 30 selects between two feasible replacement-event plans, comparing capacity/resource use with the original attendees' expectations. It no longer treats comforting someone and then finding another activity as mutually exclusive behaviors.
- The strategy/heritage adaptive contrast now compares two versions of the same town treasure trail. It no longer presents unrelated route design and oral-history collection as separate activities that could simply both be done.
- Bon Bon's career image uses a separate 1280×1455 transparent PNG, distinct from the existing standing cover/profile asset. The career renderer retains object-fit: contain. Source: https://www.nicepng.com/ourpic/u2w7u2i1w7i1i1u2_sweetie-drops-bon-bon-my-little-pony/

## Counting and compatibility

The first three acts still contain eight framework questions and four tasks each. The fourth act contains eight framework questions followed by four adaptive-or-ordinary slots. Every complete path has 48 displayed questions. Earlier form v1/v2/v3 scorers are retained on the server, so open older clients and saved reports are not silently reranked. New drafts use a separate storage key.

Rewording changes the response process and needs participant review. Retaining an axis and numeric direction is not evidence that an item has unchanged validity. The original shared question bank is not mutated: new wording lives in a cloned v4 form.

## Checks

The 20,000-run uniform-ordinal simulation retains all 36 strict role witnesses. Close candidates change from 38.295% in v3 to 34.945% in v4. Main-six combined share changes from 15.835% to 15.400%; Sweetie Belle changes from 4.660% to 4.705%, and Daring Do from 3.815% to 4.170%. More adaptive slots therefore do not establish better accuracy or lower concentration for every character.

These distributions include close cases, keep the same close threshold and do not represent real-user rates. Four adaptive slots were accepted to provide more opportunities for candidate checks without increasing length, not because human classification validity has been established. Per-role bonuses or quotas were not added.

Tests cover versioned backend witnesses, four-slot validation and replay, the existing main-six contrast pairs, midpoint/neutral-response behavior, all chapter dialogs on phone and desktop, no question hint label, full result reopening and a separate contained Bon Bon career image.
