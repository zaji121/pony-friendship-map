# 主角团接近结果优先展示（V6）

本规则由用户明确要求提高主角团出现比例而引入，属于产品排序偏好，不是心理测量准确性改进，也不设定强制比例或角色配额。

只在完成48题后的最终排序应用；不改变选题路线、四维答案、四维百分比、原始匹配分数或角色支持证据。若原第一候选为非主角团角色，主角团候选需同时满足：

1. 双方都有至少两个场景、两类特征的支持。
2. 综合匹配分数与原第一候选相差不超过0.03。
3. 若双方有四维匹配分数，主角团候选在该项落后也不超过0.03。

满足时优先展示最靠前的主角团候选，原第一候选保留为另一位候选；结果明确标注“主角团优先”，并存储原候选、分数差和实际触发状态。明显更符合的其他角色不被替换。

在相同种子、相同随机作答分布的20,000份模拟中：主角团合计由15.410%变为19.010%，720份（3.600%）最终展示顺序改变。这是模拟分布变化，不是真人出现率、准确率或效度。

36位角色各有稳定排第一的测试答案。该检查考虑了优先门槛，不能把原始分数第一直接等同最终展示第一。

V5冻结于 `public/quiz-form-48-v5.js`。后端保留V1–V6，未完成的V4、V5答卷继续原规则，历史结果不重新分配。旧缓存页面缺少V5冻结模块时按V5语义运行，避免缓存HTML把旧答卷误解释为V6。

边界、四维分数不变、旧版回放、缓存兼容及相同输入云端保存/重开均有测试。结果页把本规则披露于计分说明，职业说明仍保留自身内容。
